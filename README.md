# Drogaria Pinheiro

Site institucional em desenvolvimento para a Drogaria Pinheiro, criado com o objetivo de fortalecer a presenca digital da empresa e facilitar o acesso dos clientes a informacoes essenciais, como apresentacao da drogaria, contato, localizacao e servicos.

## Status

Em desenvolvimento.

## Objetivos do projeto

- Criar uma pagina institucional clara, responsiva e profissional.
- Apresentar a Drogaria Pinheiro de forma acessivel para clientes.
- Facilitar o contato por telefone, WhatsApp ou outros canais definidos.
- Organizar informacoes importantes sobre a empresa e seus servicos.
- Praticar desenvolvimento web com foco em projeto real.

## Tecnologias utilizadas

> Atualize esta secao conforme a stack final do projeto.

- HTML
- CSS
- JavaScript
- Git e GitHub

## Funcionalidades planejadas

- Pagina inicial com apresentacao da drogaria.
- Secao sobre a empresa.
- Secao de servicos ou produtos.
- Informacoes de contato.
- Botao de contato via WhatsApp.
- Mapa ou informacao de localizacao.
- Layout responsivo para celular, tablet e desktop.
- Otimizacao basica de acessibilidade e organizacao visual.
